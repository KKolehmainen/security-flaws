LINK: https://github.com/KKolehmainen/security-flaws

FLAW 1: SQL injection (OWASP 2021 #4)
- Allow SQL injections by raw SQL command use
- Use  %' -- to access all notes in search functionality

FLAW 2: CSRF (not in OWASP 2021)
- Not using a CSRF token to prevent cross site forgery

FLAW 3: Broken Access Control (OWASP 2021 #1)
- Allow a user to see other users' notes due to not checking for owner of the note

FLAW 4: Vulnerable and Outdated Components (OWASP 2021 #6)
- Using an old version of a package that contains a vulnerability
- Use old version db_v1 instead of new db_v2. The function name is the same but the new version is safe and old is not

FLAW 5: Security Misconfiguration (OWASP 2021 #5)
- Allow empty passwords
- Some users may accidentally or even purposefully create users without passwords
- An attacker can try to find these users by going through lists of common usernames
